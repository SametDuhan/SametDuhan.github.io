# Logo kaynakları

Anthropic, OpenAI ve Google Gemini vektörleri Simple Icons v15.0.0 paketinden alınmıştır:
https://github.com/simple-icons/simple-icons/tree/15.0.0/icons

Simple Icons dağıtımı CC0 lisanslıdır. Marka adları ve logoları ilgili sahiplerine aittir.
Bu dosyalar yalnız kişisel sitenin monitöründeki dekoratif piksel galerisi için kullanılır.
Tarayıcıda 48×48 tuvale çizilip pikselli ölçeklenir; harici ağ isteği yapılmaz.
