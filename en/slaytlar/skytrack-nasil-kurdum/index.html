1 · What does it do?

Live aircraft on a map

Screen recording: the browser demo. The flights and turbulence areas are simulated; the video is silent.

SkyTrack is a free desktop app that shows aircraft around the world live on a map. It runs on Windows, macOS, and Linux and needs no account or API key.

ADS-B: The open signal in which aircraft broadcast their position, altitude, and speed several times a second. Volunteers' receivers pick up this signal; SkyTrack uses this open data.

4 · A closer look at one decision

False emergency alarms

DECISION EXPERIMENT / ALARM THRESHOLDExample scenario
✈7700 · sample signal

How long the code persisted without a break: 1 seconds

As the threshold grows, brief signals are filtered out, but the notification is delayed too. 45 seconds is the rule chosen in this project.

Aircraft report an emergency with a code: 7500 hijacking, 7600 radio failure, 7700 general emergency. SkyTrack shows these codes with a red ring and sends a notification. Follow the problem line by line through the commits:

Oct 6 Explain squawk emergency codes (7500/7600/7700) in an in-app dialogOct 6 0.7.3: only real emergencies (7500/7600/7700 or matching ADS-B status) are shown as emergenciesOct 8 Emergencies: a squawk 7500/7600/7700 counts only after 45 s without a break (knob transit no longer fires alerts)

Claude wrote the code. But asking "why is this alarm wrong?", finding the cause, and deciding on a rule like 45 seconds is a human's job.

5 · AI gets it wrong too

One comment line broke the whole startup

On October 7, a startup error showed up in the photo viewer. The commit message says:

baslat(); // temporary note fotografi_yukle(); pencereyi_ac();
✗ the comment swallowed the rest of the line: startup broke✓ new test: every script parses without errors
Fix start-up error in the photo viewer (a comment swallowed the rest of a line); test that every script parses

So a misplaced comment turned the rest of the line into a "comment" and the code didn't run. The second half of the fix is more important: a test that checks all scripts can be read without errors was added. The same kind of error can't slip through silently again.

Lesson: when you write fast with AI, mistakes also arrive fast. The answer is not to drop AI but to have it write tests. SkyTrack's tests run automatically on GitHub with every change.
