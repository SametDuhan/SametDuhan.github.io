PROJECT · LIVE FLIGHT TRACKING

SkyTrack

AppOpen data

Live flight tracking with open ADS-B data. It needs no account or API key; it shows turbulence along the route, alerts you for the flight you follow, and suggests a seat based on which side the sun is on.

What does it do?

Turning live flight data into an experience that is easy to read on a map. The desktop app runs on open ADS-B data; the browser demo uses simulated flights.

  • Live flight trackingUses open ADS-B data; needs no account or API key.
  • TurbulenceShows turbulence along the route.
  • Flight alertAlerts you for the flight you are following.
  • Seat suggestionSuggests a seat based on which side the sun is on.
  • 15 languagesThere is also a web demo that runs in the browser.
  • On every desktopWindows, macOS, and Linux; built with Electron and Leaflet.

Development story

01

A decision I made

Instead of sending an alert the moment I saw an emergency code, I chose a rule that waits for the code to persist for 45 seconds without a break. That way I aimed to reduce false alarms from brief code flickers.

02

Issues and checks

A comment line in the photo viewer broke startup. Alongside the fix, a test that checks the syntax of all scripts was added. In the deck you can look at this example's commit message and timeline.

03

The AI's role

In the count dated 27 October 2026, 191 of the 208 commits carry a Claude co-author record. This does not mean 92 percent of the lines of code were written by AI; it shows the number of commits that have a co-authorship record.

04

For the next iteration

As a next step, one could first verify the data flow, error cases, and alert behavior in a small prototype, then add the language and desktop packages on top of that foundation.
