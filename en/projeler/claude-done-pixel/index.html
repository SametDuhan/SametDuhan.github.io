What does it do?

Reducing the need to check the terminal over and over when Claude Code finishes a long task. A short pixel animation in the corner of the screen shows that the work is done.

  • Runs on the Stop hookTriggered when Claude Code finishes its work.
  • Runs, jumps, waves a flagAn orange pixel character and a green flag in the corner of the screen.
  • Lets clicks throughDoesn't steal keyboard focus; what you're typing isn't interrupted.
  • PowerShell, no extra packagesRuns on Windows without installing anything extra.

Development story

01

A decision I made

It was important that the notification not steal focus or block clicks. While giving a visible signal, I aimed for it not to interrupt what the user was doing at that moment.

02

Issues and checks

I'm not sharing a specific, documented bug story here like the one in SkyTrack. The cases to check in the design are preserving settings, back-to-back notifications, and the window's effect on user interaction.

03

The AI's role

What matters in this project is separating the event from the visuals: the Stop hook fires the event, and PowerShell shows the animation. In the AI development walkthrough I explain this connection as much as the files that came out of it.

04

For the next iteration

As a next step, one could first confirm with a simple notification that the event is caught correctly, and add the character animation afterwards.
