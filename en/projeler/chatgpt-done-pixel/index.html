What does it do?

Letting you know with a short pixel animation above the clock on the Windows desktop when Codex completes a turn. The project supports both Windows and WSL.

  • agent-turn-completeRuns on the notification sent when Codex finishes a turn.

Development story

01

A decision I made

There is no need to save chat text or send a network request for the notification. The project focuses on the completion event.

02

Issues and checks

I'm not making up an unverified bug story on this page. The trigger path between Windows and WSL and the behavior of back-to-back completed tasks are points worth looking at when reviewing the project.

03

The AI's role

The core idea from the Claude version is tied here to a different completion event. Comparing the two projects shows how the same interface idea can run with different agents.

04

For the next iteration

One could verify the event-capture and animation layers separately and unify the different environments under the same small notification contract.
